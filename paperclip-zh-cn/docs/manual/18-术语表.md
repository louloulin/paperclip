# 第 18 章　术语表

| 英文 | 中文 | 说明 |
| --- | --- | --- |
| Paperclip | Paperclip（不译） | AI Agent 编排控制平面 |
| Company | 公司 | 顶层隔离单元，可有多个 |
| Organization | 组织 | 与公司同义的顶层概念 |
| Goal | 目标 | 公司存在的原因，可量化 |
| Project | 项目 | 通常绑定仓库/工作区 |
| Issue | 任务/工单 | 工作单元；本手册统一称「任务」 |
| Agent | 智能体/员工 | 一个 AI 员工 |
| Adapter | 适配器 | Paperclip 与 Agent 运行时之间的桥 |
| Heartbeat | 心跳 | Agent 的一次短执行窗口 |
| Delegation | 委派 | 沿汇报线把任务与权限向下分派 |
| Chain of command | 指挥链 | Agent 的树形上下级关系，用于升级 |
| Escalation | 升级 | 沿指挥链把问题上交 |
| Checkout | 签出 | 原子地占用一条任务（唯一持有者） |
| Blocker | 阻塞项 | 一等公民的依赖边 |
| Routine | 例程 | 可重复触发的任务定义 |
| Trigger | 触发器 | schedule / webhook / api |
| Approval | 审批 | 需要人点头的门禁 |
| Execution policy | 执行策略 | 挂在任务上的评审/审批阶段与 monitor |
| Monitor | 监控 | 定时唤醒复查的持久状态（`monitorNextCheckAt`） |
| Work product | 交付物指针 | PR / 预览 URL / 提交 / 分支等可检查产物 |
| Artifact | 产物文件 | 上传的附件 |
| Workspace | 工作区 | 项目目录或任务级隔离工作区 |
| Execution workspace | 执行工作区 | 单任务隔离环境（worktree / operator 分支） |
| Runtime service | 运行时服务 | 托管的 dev server / 预览 |
| Skill | 技能 | 运行时注入给 Agent 的流程说明 |
| Skill Studio | 技能工作室 | 设计/训练 Agent 员工的界面 |
| Plugin | 插件 | 实例级扩展（worker、能力、UI 贡献） |
| Connection | 连接 | 访问外部服务的通道（Apps / Connections / Review） |
| MCP | 模型上下文协议 | Agent 访问外部工具的协议层 |
| Secret | 密钥 | 加密存储的凭据，按实例/公司分域 |
| Budget | 预算 | 月度花费上限（单位：分） |
| Cost event | 成本事件 | 一次调用的 provider/model/token/费用记录 |
| Activity log | 活动日志 | 全量可审计的写操作记录 |
| Board | 看板/董事会 | 人类运营者及其控制面 |
| Board operator | 看板运营者 | 用 UI 审批、暂停、改派的人 |
| Adapter type key | 适配器类型键 | 如 `claude_local`、`process`、`http` |
| Run | 运行 | 一次心跳的执行实例 |
| Run JWT | 运行令牌 | 绑定单次运行的短期凭据 |
| Structured decision | 结构化决策 | 跨 issue 的原子化选择/生效包 |
| Interaction | 交互卡片 | 线程内的结构化请求（确认/勾选/问答/提任务） |
| Company portability | 公司可移植性 | 整家公司导出导入 |
| local_trusted | 本地可信模式 | loopback、无需登录 |
| authenticated | 需鉴权模式 | 分 private / public |
| Bind | 绑定 | loopback / lan / tailnet / custom |
| Feedback granularity | 反馈粒度 | 适配器把 Agent 输出流式反馈到 UI 的粒度 |
| UI parser | 界面解析器 | 把适配器输出解析为 UI 可渲染结构 |
| Heartbeat context | 心跳上下文 | 紧凑的任务状态 + 祖先 + 评论游标 |
| Cost of idle | 空闲成本 | Agent 不工作时不产生成本（对比常驻进程） |
| Telemetry | 遥测 | 匿名使用统计，可关闭 |
