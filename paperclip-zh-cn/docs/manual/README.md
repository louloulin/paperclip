## 阅读约定

- 命令行示例默认在 bash 下执行，`$` 开头为提示符，无需输入。
- 凡出现 `PAPERCLIP_*` 均为环境变量。
- 链接到英文原文时使用仓库内相对路径，便于与代码对照。
- 本手册中的 API 示例以 REST 为主；界面操作以「看板（Board）→ 菜单」描述。

## 版本与校对

- 手册随 Paperclip 版本滚动更新。改动手册请提交到 `paperclip-zh-cn/docs/manual/`，
  与汉化插件同一个目录，便于与词典维护一起发布。
- 英文原始文档在本仓库 `docs/`（Mintlify 结构）与 `doc/`（工程文档）中。
