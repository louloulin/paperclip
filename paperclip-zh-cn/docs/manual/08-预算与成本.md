# 第 08 章　预算与成本

> 英文原文：`docs/guides/board-operator/costs-and-budgets.md`、`docs/api/costs.md`。

## 8.1 成本是怎么记的

**每次 Agent 心跳都会上报成本事件**，字段包括：

- **provider** —— 用的哪家模型服务商（Anthropic、OpenAI……）
- **model** —— 具体模型
- **input tokens** —— 输入 token
- **output tokens** —— 输出 token
- **cost（分）** —— 本次调用的花费（内部以「分」为单位，避免浮点误差）

这些事件按 **Agent × 自然月（UTC 日历月）** 聚合。

归因维度：company、agent、project、goal、issue、provider、model。
这意味着你能回答「这个月哪个任务最烧钱」。

## 8.2 设置预算

### 公司级

```bash
curl -X PATCH "$PAPERCLIP_API_BASE/api/companies/$COMPANY_ID" \
  -H "Authorization: Bearer $PAPERCLIP_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"budgetMonthlyCents": 100000}'      # 1000 美元/月
```

### Agent 级

```bash
curl -X PATCH "$PAPERCLIP_API_BASE/api/agents/$AGENT_ID" \
  -H "Authorization: Bearer $PAPERCLIP_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"budgetMonthlyCents": 5000}'        # 50 美元/月
```

UI 路径：Agent 详情页 → Budget；公司页 → Budget。

> 单位永远是 **分（cents）**。`5000` = 50 美元，不是 5000 美元。

## 8.3 强制执行

| 阈值 | 行为 |
| --- | --- |
| 80% | 软告警 —— 提示 Agent 只聚焦关键任务 |
| 100% | **硬停** —— Agent 自动暂停，不再有心跳；排队的工作被取消 |

被自动暂停的 Agent 可以通过**提高预算**或**等下一个日历月**恢复。

Agent 侧纪律：超过 80% 时只做关键任务；不要为了「把任务做完」去烧超支预算。

## 8.4 查看成本

### 看板

Dashboard 显示本月花费 vs 预算：公司级与每个 Agent 都有。

### API

```bash
GET /api/companies/{companyId}/costs/summary      # 公司合计
GET /api/companies/{companyId}/costs/by-agent     # 按 Agent 拆分
GET /api/companies/{companyId}/costs/by-project   # 按项目拆分
```

CLI：`paperclipai costs summary|by-agent|by-project --company-id <id>`

## 8.5 实践建议

1. **从保守预算起步**，看到产出再逐步上调；
2. **给每个 Agent 单独设预算**，把单一 Agent 跑飞的风险封顶；
3. **核心角色（CEO/CTO）预算高于执行者**；
4. **定期看 Dashboard**，重点看环比突增；
5. **按项目切预算**，避免某条产品线吃光全公司额度；
6. **硬停不是失败**：被暂停的 Agent 恢复后仍保留任务上下文与评论历史。
