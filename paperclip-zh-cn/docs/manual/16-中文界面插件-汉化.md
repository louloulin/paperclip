# 第 16 章　中文界面插件（汉化）

> 本章介绍本仓库自带的独立插件 `paperclip-zh-cn/`：把 Paperclip 整个 Web 界面**动态**翻译成简体中文。
> 手册本身也是中文的，但界面汉化由这个插件提供，两者是独立产物。

## 16.1 它是什么

- **独立项目**：不进入 Paperclip 主仓库的 pnpm workspace，不修改宿主任何一行代码；
- **动态汉化**：运行时遍历 DOM 翻译文本节点与 `placeholder` / `title` / `aria-label` / `alt`，
  用 `MutationObserver` + 定时兜底扫描覆盖后渲染的内容（软导航、弹窗、流式输出）；
- **可回滚**：每处替换都记录原文，`stop()` / 卸载 / 组件卸载时逐字还原页面，
  回滚是「零残留」而不是「刷新页面」；
- **无构建**：`src/` 即 ESM 产物，`node scripts/build.mjs` 只做拷贝 + 清单校验，可在离线实例上安装。

## 16.2 安装

```bash
cd paperclip-zh-cn
node bin/paperclip-zh.mjs install        # 构建 → 快照当前状态 → paperclipai plugin install/enable
```

安装后**刷新浏览器标签页**，右下角出现 `中/EN` 开关。
默认 `auto`：浏览器首选语言为 `zh-*` 时自动汉化。

手动走宿主 CLI（等价）：

```bash
node scripts/build.mjs
paperclipai plugin install "$PWD" --local
paperclipai plugin enable paperclip.zh-cn
```

## 16.3 回滚与卸载

| 需求 | 命令 | 效果 |
| --- | --- | --- |
| 临时回滚（推荐） | `node bin/paperclip-zh.mjs rollback` | `plugin disable`，界面立即恢复英文；插件与状态保留，`install` 可原样恢复 |
| 回滚到指定版本 | `node bin/paperclip-zh.mjs rollback --to 1.0.0` | 停用后重装清单版本为该版本的构建 |
| 完全卸载 | `node bin/paperclip-zh.mjs uninstall` | `plugin uninstall`，保留插件状态 |
| 彻底清除 | `node bin/paperclip-zh.mjs uninstall --force --yes` | 同时清除插件状态与配置（需二次确认） |

`install` / `rollback` / `uninstall --force` 都会先把 `paperclipai plugin inspect` 快照写入 `.state/`，
便于事后审计。

## 16.4 能力授权

安装前需要在宿主的插件能力审核里批准三个能力：

- `ui.action.register` —— 注入界面上的中/EN 开关；
- `plugin.state.read` / `plugin.state.write` —— 仅用于记录语言偏好，**不读写任何业务数据**。

拒绝其中任何一个，界面照常可用，只是没有右下角开关，需要靠浏览器语言自动判定。

## 16.5 配置

| 键 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `mode` | `auto` \| `on` \| `off` | `auto` | 依浏览器语言 / 始终汉化 / 始终英文 |
| `translateAttributes` | boolean | `true` | 同时翻译 `placeholder`/`title`/`aria-label`/`alt` |
| `skipCodeBlocks` | boolean | `true` | 跳过 `<pre>`/`<code>` 与可编辑区域 |

## 16.6 词典维护

词典是「英文原文 → 中文」的**纯字面量表**（`src/i18n/dictionary.zh-cn.js`），不含正则与模板。
因此宿主改名某个字符串只会导致那一条不再翻译，**不会让运行时出错**。

```bash
node scripts/extract-strings.mjs                       # 扫描 ../ui/src，产出 analysis/ui-strings.json（6588 条候选）
node scripts/extract-strings.mjs --out /tmp/strings.json
node --test "tests/*.test.mjs"                          # 25 个用例：翻译、运行时、还原保证、清单与宿主目录一致
```

流程：抽取候选 → 人工审校 → 合并进词典 → 跑测试。

## 16.7 与本手册的关系

- 本手册（`paperclip-zh-cn/docs/manual/`）是**文档级汉化**，永久可读、可用全文搜索、可离线；
- 汉化插件是**界面级汉化**，跟随宿主版本，可能需要跟随上游更新词典；
- 两者独立：插件回滚不影响手册，宿主升级也不会删掉手册。

## 16.8 常见问题

| 现象 | 处理 |
| --- | --- |
| 界面仍是英文 | 刷新标签页；检查右下角开关是否为 `EN`；用 `node bin/paperclip-zh.mjs status` 查看状态 |
| 某句没翻译 | 上游改了字符串。跑 `extract-strings.mjs` 重新抽取，补充词典条目 |
| 代码块里的中文乱了 | 保持 `skipCodeBlocks: true`（默认） |
| 页面出现混杂中英文 | 该字符串不在词典里，属预期；补词典或等上游词典更新 |
| 想彻底恢复 | `node bin/paperclip-zh.mjs uninstall --force --yes` |
