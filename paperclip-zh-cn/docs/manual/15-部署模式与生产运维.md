# 第 15 章　部署模式与生产运维

> 英文原文：`docs/deploy/*.md`、`doc/DOCKER.md`、`doc/DEPLOYMENT-MODES.md`、`doc/observability.md`。

## 15.1 两种运行模式

可达性（是否对外暴露）由 `bind` 单独配置，安全剖面由部署模式决定。

### `local_trusted`（默认）

| 项 | 值 |
| --- | --- |
| 绑定 | 仅 loopback |
| 鉴权 | **不需要登录** |
| 看板身份 | 自动创建的本地看板用户 |
| 适用 | 本地开发、个人试验 |

```bash
npx paperclipai onboard        # 选 "local_trusted"
```

### `authenticated`

需要登录（Better Auth），分两种暴露策略：

**`authenticated` + `private`（Tailscale / VPN / 局域网）**

- 鉴权：需登录；
- URL：自动 base URL 模式（摩擦最小）；
- 需配置私有主机信任策略；
- `bind` 可选 `loopback` / `lan` / `tailnet` / `custom`；
- 自定义 Tailscale 主机名：`npx paperclipai allowed-hostname my-machine`。

**`authenticated` + `public`（面向互联网）**

- 需登录，且必须显式提供公网 URL；
- `paperclipai doctor` 会执行更严格的安全检查；
- 通常 `bind loopback` + 反向代理；`lan`/`custom` 属于高级用法。

```bash
npx paperclipai onboard        # 选 "authenticated" → "private"/"public"
```

## 15.2 董事会认领流程

从 `local_trusted` 迁到 `authenticated` 时，服务启动打印一次性认领链接：

```
/board-claim/<token>?code=<code>
```

已登录用户访问后：该用户被提升为实例管理员；自动创建的本地看板管理员被降级；
并保证该用户是活跃公司成员。

## 15.3 切换模式

```bash
npx paperclipai configure        # 或直接改配置文件后重启
```

切换后**必须**确认：认领链接已被使用、CLI 已拿到 board token（否则任何写操作 401）、
健康检查里的 `bootstrapStatus` 正常。

## 15.4 数据库

- 本地默认使用**内嵌 PostgreSQL**，无需配置；
- 生产建议指向自己的 PostgreSQL；迁移用 `pnpm db:migrate`；
- 备份：`pnpm db:backup`（`scripts/backup-db.sh`）；
- 数据库文档：`docs/deploy/database.md`，表结构见 `doc/DATABASE.md`。

## 15.5 存储

- 本地：本地文件存储（`~/.paperclip` 或 `--data-dir`）；
- 生产：可配对象存储 provider（见 `docs/deploy/storage.md`）；
- 附件与 work product 走同一套存储抽象。

## 15.6 密钥与配置

- 实例密钥 / 公司密钥分两层，见 [第 11 章](./11-技能插件连接与密钥.md)；
- 云端密钥可用 provider 支撑（`doc/SECRETS-AWS-PROVIDER.md`）；
- 环境变量总表：`docs/deploy/environment-variables.md`；
- 关键环境变量：`PAPERCLIP_*` 系列、`DATABASE_URL`、provider API key、
  `OTEL_EXPORTER_OTLP_ENDPOINT`、`SENTRY_DSN_FRONTEND` / `SENTRY_DSN_BACKEND`。

## 15.7 可观测性

### OpenTelemetry（仅 trace，可选）

设置 `OTEL_EXPORTER_OTLP_ENDPOINT` 即可激活服务端自动埋点；
协议用 `OTEL_EXPORTER_OTLP_PROTOCOL`（支持 `grpc`、`http/protobuf`、`http/json`）。
SDK、自动埋点与 exporter 是**可选 peer 依赖**，要 trace 才装。详见 `doc/observability.md`。

### Sentry（可选）

- `SENTRY_DSN_FRONTEND` —— 浏览器端；
- `SENTRY_DSN_BACKEND` —— 服务端；
- 旧变量 `SENTRY_DSN` 仍可作为回退。
服务端 SDK 固定为 `@sentry/node@10.71.0`，浏览器为 `@sentry/browser` 同一精确版本，
**都是可选 peer 依赖**。

## 15.8 遥测与隐私

Paperclip 默认收集**匿名使用遥测**；不收集个人信息、任务内容、提示词、文件路径或密钥。
私有仓库引用会带**按安装加盐**的哈希后才上报。

关闭方式：

| 方式 | 做法 |
| --- | --- |
| 环境变量 | `PAPERCLIP_TELEMETRY_DISABLED=1` |
| 通用约定 | `DO_NOT_TRACK=1` |
| CI | `CI=true` 时自动关闭 |
| 配置文件 | 配置里 `telemetry.enabled: false` |

## 15.9 生产检查清单

- [ ] 模式为 `authenticated`（对外）或 `authenticated + private`（内网）；
- [ ] 已完成董事会认领，`bootstrapStatus` 正常；
- [ ] 前置反向代理 + TLS，宿主信任策略已配置；
- [ ] PostgreSQL 独立实例，备份策略已验证；
- [ ] 存储指向对象存储，附件可下载；
- [ ] 公司级与 Agent 级预算已设置；
- [ ] 审批门（招聘 / 战略 / 支出）按需开启；
- [ ] `paperclipai doctor` 无告警；
- [ ] 遥测策略已按合规要求决定；
- [ ] 实验特性默认保持关闭。

## 15.10 备份与可移植

- 整家公司可导出为可移植包（manifest + markdown），含 Agent、技能、项目、例程、任务；
- 导出时自动脱敏密钥，导入时处理冲突（`--collision rename`）；
- 云托管实例不支持导入（`403 cloud_managed`），导出仍可用。
